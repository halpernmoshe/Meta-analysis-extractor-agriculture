# 025_Guo_2011 - Agent Extraction

## Paper Details
- **Title**: Elevated CO2 Levels Affects the Concentrations of Copper and Cadmium in Crops Grown in Soil Contaminated with Heavy Metals under Fully Open-Air Field Conditions
- **Authors**: Guo, Zhu, Zhou, Sun, Yin, Pei, Ji, Wu, Wang
- **Year**: 2011
- **Journal**: Environmental Science & Technology
- **Species**: Oryza sativa (rice, cv. Wuxiangjing 14), Triticum aestivum (wheat, cv. Yangmai 14)
- **Experiment**: FACE, Xiaoji, Jiangdu County, Jiangsu Province, China
- **CO2 levels**: Ambient ~370 ppm, Elevated ~570 ppm (+200 ppm)
- **Duration**: 2006-2008, rice-wheat rotation
- **n**: 3 replicate pots per treatment

## Design
- **Cu experiment**: Soils spiked with 0, 50, 400 mg/kg Cu
- **Cd experiment**: Soils spiked with 0, 0.5, 2.0 mg/kg Cd
- Two crops (rice, wheat), multiple growth stages, 2 sowing seasons each
- Data presented in Figures 1-4 (bar charts with SD error bars)
- Only Cu and Cd concentrations reported (no other mineral elements)

## Data Source
All data from Figures 1-4 (bar charts). Values estimated from figures and cross-checked with percentage changes reported in text. The paper also mentions Supporting Information Table S2 but this is not included in the main article.

## Notes
- Cu consistently DECREASED under elevated CO2 (all negative effects)
- Cd consistently INCREASED under elevated CO2 (positive effects, especially at high Cd contamination)
- This is a factorial design: CO2 x metal contamination level
- The Loladze meta-analysis may only use Cu data from control soils (0 mg/kg added) since it focuses on uncontaminated conditions
- Values read from bar charts have inherent uncertainty of approximately +/-5-10%
