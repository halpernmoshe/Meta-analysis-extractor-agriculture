# 021_Wilsey_1994 - Agent Extraction

## Paper Details
- **Title**: Will increases in atmospheric CO2 affect regrowth following grazing in C4 grasses from tropical grasslands? A test with Sporobolus kentrophyllus
- **Authors**: Wilsey, McNaughton, Coleman
- **Year**: 1994
- **Journal**: Oecologia (99:141-144)
- **Species**: Sporobolus kentrophyllus (C4 grass, Serengeti)
- **Experiment**: Growth chamber, 370 vs 700 ppm CO2
- **Design**: 2x2 factorial: CO2 (370 vs 700 ppm) x Clipping (clipped vs unclipped)
- **Replicates**: n=9 per CO2 x clipping cell (3 harvest dates x 3 replicates, 2 trials)
- **Tissue**: Leaf

## Data Source
- **Table 1**: Leaf nutrient concentrations (mean in mg/kg with SE), harvest dates combined
- No significant CO2 effect on any nutrient (all P > 0.05)
- No CO2 x clipping interaction for any nutrient

## Notes
- The paper also mentions V (Vanadium) in the text as a measured element but it does not appear in Table 1
- Co (Cobalt) clipped shows large negative effect (-56.9%) but high SE in control (3.2) suggests high variability; not statistically significant
- Fe increased under elevated CO2 in both clipping treatments (unusual direction)
- All nutrient concentrations were non-significant between CO2 treatments (P > 0.05)
- Figures 1A-E show biomass data only (not mineral concentrations), so no additional mineral data from figures
