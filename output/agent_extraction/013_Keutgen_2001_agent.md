# 013_Keutgen_2001 - Agent Extraction

## Paper Info
- **Title**: Responses of citrus leaf photosynthesis, chlorophyll fluorescence, macronutrient and carbohydrate contents to elevated CO2
- **Authors**: Keutgen N, Chen K
- **Year**: 2001
- **Journal**: J. Plant Physiol. 158, 1307-1316
- **Species**: Citrus madurensis Loureiro (Calamondin)
- **Experiment**: Growth chamber, 90 days
- **CO2 levels**: 300 (control), 450, 600, 750, 900 ppm
- **n**: 3 per treatment (for macronutrient analyses)

## Data Source
- **Table 3**: Macronutrient and total chlorophyll contents (mg/g dry matter)
- Elements measured: N, P, K, Ca, Mg
- Leaf ages: young (<4 weeks), fully expanded (5-12 weeks), old (>13 weeks)

## Notes
- Only macronutrient data (N, P, K, Ca, Mg) reported; no microelements (Fe, Zn, Mn, Cu, etc.) measured
- Control = 300 ppm CO2 (pre-industrial level)
- N showed strongest and most consistent decline, especially in fully expanded and old leaves
- P, K, Ca, Mg generally not significantly affected (per paper text and statistical annotations)
- Chlorophyll data also in Table 3 but not a mineral element
- No additional element data in figures (Fig. 2 is a carpet plot of gas exchange/fluorescence ratios)
- Carbohydrate data in Table 4 (starch, glucose, fructose, sucrose) - not mineral elements
