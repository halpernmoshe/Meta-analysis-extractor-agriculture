# Extraction: Oksanen et al. 2005

## Paper Details
- **Title**: Structural characteristics and chemical composition of birch (Betula pendula) leaves are modified by increasing CO2 and ozone
- **Journal**: Global Change Biology, 11, 732-748
- **Species**: Betula pendula (silver birch), clones 4 (O3-tolerant) and 80 (O3-sensitive)
- **Experiment**: Open-top chambers, 3 growing seasons (1999-2001), central Finland
- **CO2 levels**: Ambient ~365 ppm (CC) vs Elevated ~720 ppm (EC, 2x ambient)
- **Design**: Randomized incomplete blocks, n=4 replicate trees per treatment

## Data Source
- **Table 8** (page 11): Foliar nutrient concentrations, pooled clones 4+80, averaged July 2000 and 2001
- This is the only table with actual mineral concentration values (mean +/- SD)
- Tables 2-4 contain only P-values (ANOVA results), not concentration data
- Tables 5-6 contain structural/anatomical data, not mineral concentrations
- Figures show cell wall chemistry (% dry mass) and structural data, not mineral concentrations

## Notes
- 11 mineral elements extracted from Table 8
- P-values from Table 3 (CO2 main effect in repeated measures ANOVA)
- Significant CO2 effects (P<0.05): N, K, Cu, S (all decreased), Fe (borderline P=0.079)
- P:N ratio increased under elevated CO2 (17.2% to 19.1%), consistent with greater N decline
- This is a factorial design with CO2 x O3; only CC vs EC comparison extracted (CO2 effect only)
- The OC (outside control) column excluded as it is not part of the CO2 treatment comparison
- EO and EC+EO columns excluded as they involve ozone treatment
- Clones pooled in Table 8 (as presented by authors); Table 3 shows no significant CO2 x clone interactions for nutrients
