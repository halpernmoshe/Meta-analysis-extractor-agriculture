# 016_Fernando_2012a - Data Extraction

## Paper
**Title:** Wheat grain quality under increasing atmospheric CO2 concentrations in a semi-arid cropping system
**Authors:** Fernando et al. (2012)
**Journal:** Journal of Cereal Science 56: 684-690
**Species:** Triticum aestivum L. cv. Yitpi (wheat)
**Experiment:** FACE (Free-Air CO2 Enrichment), AGFACE site at Walpeup, Victoria, Australia
**CO2 levels:** Ambient ~384 ppm vs Elevated ~550 ppm
**Design:** 2 CO2 levels x 2 sowing times (TOS1=normal, TOS2=late) x 2 years (2008, 2009), n=4 per combination, n=16 total

## Data Sources
- **Figure 1a:** Macronutrient concentrations (K, P, S, Mg, Ca) in g/kg - average across 4 environments
- **Figure 1b:** Micronutrient concentrations (Mn, Fe, Zn, Na, Cu) in mg/kg - average across 4 environments
- **Text:** Percentage changes and protein/N data
- **Note:** Fe, Zn, S, Ca data originally from Fernando et al. (2012) companion paper, included in Figure 1

## Important Notes
- Data presented as AVERAGES across all 4 environments (2008-TOS1, 2008-TOS2, 2009-TOS1, 2009-TOS2)
- Individual environment data is shown only in Figure 2 for protein, phytate, TGW, yield, diameter - NOT for minerals
- No table with individual mineral concentration values by environment is provided
- Table 2 shows only ANOVA significance levels, not actual values
- B (boron) is mentioned in ANOVA Table 2 but no concentration values are shown in any figure

## Summary of Effects
- **Significantly decreased at eCO2:** Ca (-11%), P (-11%), Na (-19%), Fe (-10%), S (-7%), Mg (-7%), N (-12.5%)
- **Trend (p=0.07):** Zn (-17%)
- **Not significant:** K, Cu, Mn
- **Phytate:** decreased ~17% (trend, p<0.10) - not included as mineral element
- **Grain N/S ratio:** declined 6% at eCO2

## Caveats
- Values are estimated from bar charts (Figure 1) - exact numerical values not provided in tables
- The paper reports percentage changes in text that guided estimation
- B (boron) appears in ANOVA table but no concentration data is plotted or tabulated
- Individual environment breakdowns for minerals are not available (only averaged data shown)
