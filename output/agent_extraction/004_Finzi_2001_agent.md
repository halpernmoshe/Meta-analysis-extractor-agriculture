# 004_Finzi_2001 - Agent Extraction

## Paper Details
- **Title**: Forest Litter Production, Chemistry, and Decomposition Following Two Years of Free-Air CO2 Enrichment
- **Authors**: Finzi, Allen, DeLucia, Ellsworth, Schlesinger
- **Year**: 2001
- **Journal**: Ecology, 82(2), pp. 470-484
- **Experiment**: Duke FACE (Free-Air CO2 Enrichment)
- **CO2 levels**: Ambient ~360 uL/L vs Elevated +200 uL/L (~560 uL/L)
- **Species**: Pinus taeda (loblolly pine), Cercis canadensis (red bud), Cornus florida (dogwood), Acer rubrum (red maple), Liquidambar styraciflua (sweet gum)
- **n**: 3 replicate plots per treatment

## Data Sources
- **Table 2**: Green-leaf N and P concentrations (mg/g), Leaf-litter N and P concentrations (mg/g)
- **Table 3**: Leaf-litter C (%), Lignin (%), TNC (%)
- **Table 4**: Litterfall mass fluxes and nutrient-use efficiency (not element concentrations - excluded)
- **Table 5**: Decomposition N and P remaining (%) - not concentration data
- **Table 6**: Soil inorganic N - not plant tissue concentration data

## Notes
- Red maple and sweet gum green-leaf data not available for 1997 (marked NA in Table 2)
- Loblolly pine has two cohorts (new/old needles) for green-leaf chemistry
- Loblolly pine leaf litter only has old-cohort data (new needles not yet senesced)
- No other mineral elements (K, Ca, Mg, Fe, Zn, Mn, Cu, S, B, Na, Mo, Si) were measured in this study
- Elements measured: N, P, C, lignin, TNC
