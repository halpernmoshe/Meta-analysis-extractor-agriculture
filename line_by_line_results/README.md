# Supporting analysis: outcome-blind line-by-line matching (Table S6 / §3.3)

This folder contains the **canonical outputs** of the *supporting* line-by-line
matching analysis reported in Section 3.3 and Table S6 of the manuscript, together
with the deterministic join script that produced them (`../join_and_score.py`).

## What the analysis does

`join_and_score.py` is a pure deterministic **equality join** on a canonical
structural key — `(paper_id, outcome_canonical, crop, treatment_level,
co_amendment, co_amendment_level, timepoint, aggregation_level)` plus
`unit_canonical`. **No outcome value is consulted to choose a pairing**;
treatment/control means are read only to *score* rows that the key already paired
(verdict per reference row: MATCH / AMBIGUOUS / NO_MATCH). This is the bias-critical
"LLM drafts, code decides" step described in §2.5.1.

## Provenance of each dataset's numbers

The per-dataset decoded key tables were produced by the matching pipeline
(`matching/keys_from_jsonl.py` → `matching/apply_vocab_map.py`, which normalizes
synonymous vocabulary *before* the blind join). The canonical line-by-line run
versions are:

| Dataset (display) | Run version | MATCH | Coverage | On-matched treatment-mean r |
|---|---|---|---|---|
| Boldorini et al. 2024 | `boldorini`  | 19  | 95.0% | 1.00 |
| Li X et al. 2024      | `biochar_v3` | 211 | 81.2% | 0.98 |
| Loladze 2014          | `loladze_v3` | 346 | 45.9% | 0.91 |
| Hui et al. 2025       | `hui_v4`     | 19  | 3.5% raw* | 0.99 |
| Li J et al. 2022      | `li2022_v4`  | 50  | 4.5% | (omitted from scatter; unit-confounded) |

\* The manuscript reports Hui coverage as **4.3%** (19 / 444 reference table rows):
the 444 denominator is the **clean** reference set, after the 8 mislabelled-PDF
papers' rows are excluded (§2.6.3, §3.4.2). The deposited `Hui_2025/report.json` is
the raw (pre-exclusion) run at 19 / 546 = 3.5%; both report the same 19 MATCH rows.

## Files

For each dataset: `report.json` (counts, match rate, on-matched treatment/control
agreement) and `classification.csv` (every reference row → verdict).

## Note on reproduction scope

This curated repository ships the **primary** analysis as a one-command reproduction
(`../scope_matched_equivalence.py` over `../runs/<ds>/keys`). The frozen blind *pairings*
behind the supporting analysis are bundled under `../runs/<version>/pairings/`, and
`../bland_altman_figS6.py` reproduces the on-matched agreement and limits of agreement
(Figure S6, Table S10) directly from them. The `report.json` files in this folder are the
canonical line-by-line outputs (generated by `../join_and_score.py` on the
vocabulary-normalized keys, the normalization step — `apply_vocab_map.py` — being part of
the full development pipeline); they are deposited here so the reported coverage and
on-matched agreement are directly inspectable. The `join_and_score.py` tool itself is at
the repository root and can be re-run against any pair of decoded-key tables.
