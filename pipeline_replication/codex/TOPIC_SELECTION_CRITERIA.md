# Topic Selection Criteria For Pipeline V2

## Goal

Select a new preregistered topic set that gives Pipeline v2 a fair and informative evaluation.

## High-Priority Criteria

### 1. Clear Estimand

The topic should have one obvious primary estimand.

Good:
- grain yield
- crop yield
- direct harvested biomass

Bad:
- mixed system productivity + component yield
- topics where benchmark and primary papers usually report different constructs

### 2. Clear Intervention / Comparator Definition

Good:
- one intervention with explicit operational meaning
- one clean comparator

Bad:
- umbrella terms covering multiple distinct practices
- intervention labels that routinely blur into neighboring categories

### 3. Limited Study-Setting Heterogeneity

Good:
- mostly field studies
- or mostly one setting consistently

Bad:
- benchmark is field-focused but accessible corpus is mostly pot/greenhouse

### 4. Strong OA Feasibility

Good:
- many OA papers expected
- likely to recover enough primary studies

Bad:
- literature mostly locked behind paywalls
- likely severe download bottleneck

### 5. Benchmark Paper With Explicit Methods

Good benchmark paper:
- explicit intervention definition
- explicit comparator definition
- explicit outcome logic
- explicit moderator structure
- enough methodological detail to build a benchmark spec

### 6. Low Estimand Trap Risk

Avoid topics where the same label hides fundamentally different constructs.

Examples of traps:
- `LER` vs component yield
- no-till vs conservation agriculture
- organic system vs amendment trials

## Secondary Criteria

### 7. Moderators Extractable From Typical Papers

The key benchmark moderators should be recoverable from PDFs with a reasonable prompt.

### 8. Manageable Effect Direction

Prefer topics where the benchmark effect is not dominated by highly context-specific sign flips unless those contexts are easy to extract and normalize.

### 9. Benchmarkable Literature Size

Big enough to matter, but not so huge that the download bottleneck makes the run impossible.

### 10. Reporting Standardization

Prefer literatures where treatment/control yield reporting is reasonably standardized.

## Suggested Scoring Dimensions

Each candidate topic can be scored from 1 to 5 on:

- estimand clarity
- intervention clarity
- comparator clarity
- study-setting consistency
- OA feasibility
- benchmark-spec richness
- moderator extractability
- low estimand-trap risk

Total score then helps rank candidates prospectively.
