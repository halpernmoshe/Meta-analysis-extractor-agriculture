## Most Important Finding

High convergence is not enough.

The subset contains papers with perfect or near-perfect convergence that are still wrong for benchmark purposes:

- `011_Huluka_1994`: consistent extraction, but wrong timepoint / coverage limitation
- `021_Wilsey_1994`: consistent extraction, but wrong aggregation target (clipped + unclipped issue)
- `044_Housman_2012`: consistent extraction, but wrong aggregation target (per-year vs rainfall-averaged)

This means the project should not treat agreement as truth. The relevant distinction is:

- convergent and benchmark-aligned
- convergent but structurally misaligned
- low-convergence / disagreement-heavy

## Useful Technical Improvement

The original claim-level support features were understated because claim keys were too brittle.

Fixes added:

- element normalization: `CA -> Ca`, `FE -> Fe`, etc.
- tissue normalization: `whole plant -> whole`, `above ground -> aboveground`, `tubers -> tuber`, `foliar -> leaf`
- relaxed element-level support features in addition to exact claim matching

This recovered expected cross-model support for papers like:

- `020_Overdieck_1993`
- `021_Wilsey_1994`

Without this, the analysis would confuse vocabulary mismatch with epistemic disagreement.

## Interpretation

The expanded subset now supports a more useful framing for the project:

1. Some bad cases are disagreement-heavy and structurally messy.
2. Some bad cases are highly convergent but still wrong because all models latched onto the same wrong timepoint or averaging rule.
3. Therefore the right model is not a hallucination detector in the narrow sense.
4. It is a broader extraction-risk model that distinguishes:
   - clean support
   - alignment/structure problems
   - extraction coverage problems

## Best Next Steps

1. Add strict vs relaxed matching tiers explicitly to the schema, rather than relying on one claim key.
2. Add within-paper evidence channels:
   - abstract
   - results text
   - tables
   - figure captions
   - conclusion
3. Use the existing audit subset as the first benchmark set for testing whether internal convergence helps distinguish:
   - convergent-but-wrong
   - convergent-and-right
   - disagreement-heavy
4. Expand beyond the 14-paper subset once the within-paper features are working.
