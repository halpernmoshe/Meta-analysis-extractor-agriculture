# Agriculture-Only Topic Shortlist Guide For Pipeline V2

## Purpose

This note narrows the next-step topic discussion to agricultural topics only.

The goal is not to choose topics that are merely easy.
The goal is to choose agricultural topics that give Pipeline v2 a fair and informative prospective test.

## What Makes An Agricultural Topic Good For V2

A strong agricultural validation topic should have:

- one clear intervention
- one clear comparator
- one direct primary yield outcome
- little estimand ambiguity
- limited study-setting heterogeneity
- benchmark papers with explicit inclusion logic
- reasonably strong OA feasibility
- primary papers that report treatment and control clearly

## What Makes An Agricultural Topic Bad For V2

Avoid topics where:

- the topic label hides multiple estimands
- component yield and system productivity get mixed
- the intervention label covers several different practices
- field, pot, and greenhouse studies are heavily mixed
- benchmark comparability depends on subtle moderator rules
- outcomes often drift into quality, biomass, or proxy traits

  - likely a useful v2 stress test

### Middling current candidates

  - needs stricter outcome and system-comparison discipline

- `mycorrhiza_yield`

  - but highly heterogeneous in setting and co-interventions

### Weak current validation candidates

- `notill_tillage`
  - too much drift into broader conservation-agriculture context
  - difficult to keep intervention definition clean

- `intercropping_yield`
  - major estimand trap unless explicitly restricted to one system-level metric

## Preferred Pattern For New Agriculture-Only V2 Topics

For the next preregistered evaluation, prioritize agricultural topics that look like:

- one amendment or inoculant vs no amendment
- one well-defined management practice vs a clear baseline
- direct harvested yield as the primary endpoint
- mostly field experiments or one predeclared setting class
- benchmark paper with explicit operational definitions

## Recommendation

Use the current agricultural topics as retrospective development cases first.

Then choose new agriculture-only preregistered topics that are:

- semantically narrow
- outcome-clean
- comparator-clean
- setting-coherent
- benchmark-explicit

That gives Pipeline v2 the best chance of a fair prospective success.
